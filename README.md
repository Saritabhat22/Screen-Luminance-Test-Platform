# Screen-Luminance-Test-Platform
An automated test system developed to measure on-screen Luminance of a display unit at multiple Predefined points using a motorized photometer probe. The probe was mounted on a dual-axis (X-Y) motion beam driven by servo motors and PLC-based motion control, enabling precise, repeatable positioning across the screen for each measurement point.

**Problem**
Assessing on-screen brightness uniformity required accurate, repeatable readings at many specific points across the display — manual measurement was slow, inconsistent, and difficult to scale for trend analysis across units over time.

**My Role**
Designed and developed the LabVIEW application controlling dual-axis (X-Y) servo motor motion via PLC commands to precisely position the measurement probe at each defined test point
Integrated photometer-based brightness readings at each X-Y coordinate across the screen
Logged all readings to a database to enable trend analysis over time and across units
Implemented pass/fail decision logic by comparing recorded readings against preset reference values

**Tools & Technologies**
LabVIEW (application development + GUI)
Servo motor & PLC-based motion control (dual-axis positioning)
Photometer-based optical measurement
Database logging for trend analysis
Pass/fail criteria evaluation logic

**Outcome**
Enabled precise, repeatable, multi-point brightness measurement without manual probe positioning
Supported trend analysis across units and over time via centralized database logging
Delivered consistent, data-driven pass/fail decisions based on reference-value comparison
